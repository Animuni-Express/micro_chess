# ♟ Micro Chess

A professional-grade, lightweight, and 100% AI-generated chess platform. Micro Chess brings the timeless game of chess to your browser with zero downloads, offline support, and specialized modes for all devices, including e-ink readers.

![Micro Chess Banner](https://upload.wikimedia.org/wikipedia/commons/4/45/Chess_plt45.svg)

## 🚀 Key Features

- **🤖 Stockfish AI:** Challenge one of the world's strongest engines with 20 levels of difficulty. Supports local and cloud-based engine evaluation.
- **♟ Over The Board (OTB):** Play locally with a friend on the same device with a touch-responsive, beautiful interface.
- **📱 Kindle & E-Ink Optimized:** A dedicated high-contrast mode designed specifically for Kindle libraries and e-ink experimental browsers.
- **⚡ Progressive Web App (PWA):** Install Micro Chess to your home screen and play 100% offline thanks to advanced Service Worker caching.
- **♔ Smart Highlighting:** Visual indicators for valid moves and a pulsing check highlight to keep the game state clear.
- **🎨 Modern Design:** A clean, minimalist aesthetic that works perfectly on mobile, tablet, and desktop.

## 🤖 100% AI Generated

Micro Chess is a testament to modern human-AI collaboration. Every line of code, from the chess logic to the professional CSS refactoring and Service Worker implementation, was generated by AI in a single coding session.

## 🛠️ Built With

- **Logic:** [chess.js](https://github.com/jhlywa/chess.js)
- **Engine:** [Stockfish.js](https://github.com/nmrugg/stockfish.js)
- **Multiplayer:** Netlify Edge Functions and temporary PostgreSQL rooms; binary WebRTC peer gameplay.
- **Frontend:** Preact, HTML, CSS, and JavaScript; a separate Kindle UI built to ES5.
- **Offline:** Service Workers & Cache API

## 📦 Getting Started

Install Bun 1.4.4 and Node 22.12+, then run:

```sh
bun install --frozen-lockfile
bun run test
bun run build
bun run dev
```

Bun manages dependencies using `bun.lock`. The build preserves the separate Kindle ES5 bundle. Node remains the runtime for the existing test runner and Netlify tools. For local multiplayer, follow [DEPLOY.md](DEPLOY.md).

Over-the-Board and Stockfish modes run entirely in the browser. **Untimed online multiplayer** uses Netlify Database and Edge Functions for matchmaking and recovery, with direct peer connections for moves — see [`DEPLOY.md`](DEPLOY.md). Until then, online play returns an error.
